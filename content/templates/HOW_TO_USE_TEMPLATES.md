# NEPED Website Content Submission Templates
## Instructions for Officers, Project Leaders & Field Teams

Welcome! This system allows anyone on the NEPED / NEPeD team to contribute new **Projects**, **Field Reports / Blogs**, or **Gallery Photo Albums** to the website simply by filling out a standard Markdown (`.md`) or Word text document.

---

### How It Works:
1. **Choose the appropriate template:**
   - For a historical or active project ➔ [`PROJECT_TEMPLATE.md`](./PROJECT_TEMPLATE.md)
   - For a field report, technical story, or article ➔ [`BLOG_TEMPLATE.md`](./BLOG_TEMPLATE.md)
   - For an event photo album or deployment log ➔ [`GALLERY_TEMPLATE.md`](./GALLERY_TEMPLATE.md)
2. **Duplicate the template file** and rename it (e.g., `project-14-organic-coffee.md` or `blog-07-solar-hydro-hybrid.md`).
3. **Fill in the information** between the `---` dashes (the metadata) and the paragraphs below.
4. **Save and send** the `.md` or `.txt` file along with any photos (PNG/JPG) to the web team.
5. Once placed in the `/content/projects/`, `/content/blogs/`, or `/content/gallery/` folder, the website **automatically generates the new card, page, and url with ZERO code changes!**

---

### File Format Rules:
* Leave the keys (like `title:`, `date:`, `category:`) as they are, and change the text inside quotes `"..."`.
* For bullet lists, keep the `- ` dash prefix.
* For images, provide either a filename in `/public` (e.g. `"/forest.png"`) or email the high-resolution photo file along with your document.
